# HealthTracker — Документация проекта

> Персональное веб-приложение для хранения, просмотра и анализа медицинских показателей во времени.

## Что это такое

HealthTracker — self-hosted-friendly приложение для семьи из нескольких человек, позволяющее:

- вручную заносить результаты анализов (число + единица + дата);
- прикреплять к замерам PDF-бланки лабораторий и фото;
- видеть динамику каждого показателя во времени на графике с референсной полосой;
- сопоставлять показатели между собой (наложение слоёв с нормализацией);
- хранить к каждому замеру заметку в свободной форме;
- редактировать и удалять прошлые записи;
- экспортировать данные в JSON/CSV для бэкапа и в PDF-отчёт для врача.

Цель — единое персональное хранилище, которое заменяет разрозненные PDF-файлы, фотографии и бумажные бланки, и при этом даёт быстрое визуальное понимание, что происходит с здоровьем во времени.

## Краткий обзор стека

| Слой           | Технология                                                |
| -------------- | --------------------------------------------------------- |
| Frontend       | React 18 + TypeScript + Vite                              |
| UI-компоненты  | Tailwind CSS + shadcn/ui                                  |
| Графики        | Recharts (с абстракцией `<AnalyteChart/>` для перехода на ECharts) |
| Формы          | React Hook Form + Zod                                     |
| Server state   | TanStack Query                                            |
| Local state    | Zustand                                                   |
| Router         | React Router v6                                           |
| Backend        | Node.js + Fastify + TypeScript                            |
| Валидация      | Zod (общие схемы с фронтом)                               |
| ORM            | Prisma                                                    |
| БД             | SQLite (dev) → PostgreSQL (prod)                          |
| Auth           | Session cookies (httpOnly, Secure, SameSite=Strict) + bcrypt |
| Файлы          | Локальная ФС с абстракцией `StorageProvider`              |
| Reverse proxy  | Caddy (автоматический Let's Encrypt)                      |
| Деплой         | Docker Compose                                            |
| API-контракт   | REST + OpenAPI 3.1                                        |

Обоснование каждого выбора — в [03_ARCHITECTURE.md](./03_ARCHITECTURE.md).

## Терминология

Термины используются последовательно во всех документах. Запомнить ключевые:

- **Пользователь (User)** — учётная запись с e-mail и паролем.
- **Профиль (Profile)** — персональные данные для расчёта референсов (пол, дата рождения). В MVP — один профиль на пользователя.
- **Показатель (Metric)** — наименование анализа (гемоглобин, ТТГ, витамин D и т.д.) с единицей измерения. Элемент справочника.
- **Референс-диапазон (ReferenceRange)** — нормальные значения для показателя, зависят от пола и возраста.
- **Замер (Measurement)** — акт забора анализа в конкретную дату. Содержит несколько значений, заметку, вложения.
- **Значение (MetricValue)** — конкретное число для конкретного показателя в конкретном замере.
- **Вложение (Attachment)** — прикреплённый к замеру PDF/фото/другой файл.
- **Сессия (Session)** — активная аутентификация пользователя, хранится в БД, идентифицируется `sid` в cookie.
