# 06. UI / UX спецификация

Документ описывает пользовательский интерфейс HealthTracker: карту экранов, wireframes, компоненты, состояния, адаптивность, доступность и поведение графика.

## 1. Общие принципы

- **Mobile-first**. Макет вертикальный, узкий (~380px base), основные действия доступны большим пальцем. Десктопная версия — расширение, не переопределение.
- **Минимум UI-хрома**. Максимум экрана — под данные пациента. Один графический акцент — зелёная полоса референса.
- **Явная обратная связь**. После каждого действия (сохранение, удаление, ошибка) — toast / inline message.
- **Консервативная палитра**. Нейтральный фон, контрастный текст. Цветовые акценты — только для статусов (красный — отклонение, зелёный — норма).
- **Никакой лишней анимации**. Только переходы между экранами и скелетон-загрузка.

Центральная кнопка «+» — FAB, всегда открывает `/measurements/new` (основное действие).

```
┌─────────┬───────────────────────────────────┐
│         │ HealthTracker         👤 Анна ▾   │

Sidebar фиксированный слева (240px), топбар — 56px, контент с максимальной шириной 960px по центру.

### 3.3. Переход между лейаутами

Используем Tailwind breakpoints:
- `< md` (640px): мобильный таббар, без sidebar.
- `md — lg`: мобильный (таббар), контент шире.
- `≥ lg` (1024px): десктопный с sidebar.

**Состояния:**

- При ошибке API — красный toast: «Неверный e-mail или пароль».
- При 429 — красный toast: «Слишком много попыток. Попробуйте через 15 минут».

## 5. Экран «Регистрация» (/register)

Аналогично логину, но больше полей:
- E-mail
- Пароль (с индикатором силы)
- Подтверждение пароля
- Имя
- Пол (радиокнопки: женский / мужской)
- Дата рождения (date picker)

Под формой — чекбокс «Я понимаю, что это персональное приложение и не заменяет консультацию врача».

**Поведение:**

- Пустое состояние: иллюстрация + «Пока нет ни одного замера. Добавьте первый».
- Skeleton при первой загрузке: 3 карточки-плейсхолдера.
- Ошибка загрузки: «Не удалось загрузить данные» + кнопка «Повторить».

**Фильтры:**
- Кнопка 🔍 — открывает поле поиска по заметке и именам показателей.
- Кнопка 📅 — открывает drawer с выбором диапазона дат.

**Добавление показателя:**
- Клик на «+ Добавить показатель» → открывает modal/bottom-sheet с поиском.
- В поиске: автокомплит по name + synonyms, фильтр по категории.
- Выбор показателя → строка добавляется в список, фокус на поле значения.
- Единица подставляется автоматически (baseUnit), выпадающий список если есть альтернативы.

**Ввод значения:**
- Числовое поле, формат `12.5` или `12,5` (локализация при отображении, parsing принимает оба).
- При вводе в реальном времени:
  - рассчитывается флаг отклонения;
  - показывается статус («в норме» / «выше» / «ниже»);
  - показывается референс для справки.

**Прикрепление файлов:**
- Плитка «+» открывает меню: «Файл», «Фото» (на mobile открывает камеру), «Галерея».
- Во время загрузки — progress bar на плитке.
- Клик на существующую плитку — preview, клик на 🗑️ — удалить.

**Сохранение:**
- Кнопка ✓ в топбаре дублирует нижнюю «Сохранить».
- Нажатие → POST/PUT. В случае успеха — переход на карточку замера.
- При ошибке сети — inline сообщение над кнопкой, данные формы сохраняются в local state.

**Защита от потери данных:**
- Если есть несохранённые изменения и пользователь пытается уйти (стрелка назад, закрытие вкладки) — диалог подтверждения.

│  │ │        \         /   \    │  │ │
│  │ │         ●───────●      ●  │  │ │
│  │ │       ░░░░░░░░░░░░░░░░░░░ │  │ │

│  │  фев  мар      апр             │ │
│  └─────────────────────────────────┘ │
│                                       │
│  Тренд за период: ↓ −8%               │
│  Последнее значение: 108 г/л          │
│  Последнее измерение: 12 апреля       │
│                                       │
└───────────────────────────────────────┘
```

**Элементы графика:**
- Линия показателя с точками на каждом замере.
- Зелёная полоса референса (цвет `#86EFAC` с 0.3 прозрачностью).
- Точки выше/ниже нормы — с красной окантовкой.
- Между соседними точками — подпись интервала в днях (вверху графика).
- Нижний тайм-лайн «датаконтроль» — ряд кликабельных точек, синхронизирован с графиком.
- Tooltip при наведении/тапе: дата, значение, единица, отклонение в %.

**Режим наложения:**
- Если выбрано ≥ 2 показателя — режим нормализации.
- Ось Y становится «% от середины нормы», 100% — линия по центру.
- Единая полоса 80–120% (или адаптивная под узкие референсы).
- Легенда сверху с цветами и checkbox'ами.

**Состояния:**
- Показатель не выбран → «Выберите показатель для просмотра».
- Выбранный показатель без данных за период → «Нет замеров за выбранный период».
- Один замер → показываем точку + референсную полосу без линии, подпись «Мало данных для тренда».

**Интеракция:**
- Клик по точке → drawer снизу с превью замера + ссылкой «Открыть».
- Клик по точке в тайм-лайне — аналогично.
- Свайп влево/вправо — переключение периодов (3м→6м→1г→всё).
- Двойной тап на график — полноэкранный режим (future).

- Свайп по категориям вправо/влево.

**Карточка показателя (detail):**
- Название, все синонимы.
- Категория.
- Базовая единица, разрешённые единицы.
- Ваш референс (system / user-override).
- Кнопка «Переопределить референс» → модалка с min/max.
- Сколько замеров с этим показателем у меня.
- Для пользовательских — кнопка «Редактировать», «Удалить» (только если 0 замеров).

**Поведение:**
- Бэкап и PDF — асинхронные задачи, показывается progress bar.
- По готовности — auto-download и уведомление «Готово».
- CSV — синхронный, скачивается сразу.

## 13. Ключевые компоненты

### 13.1. `<ValueStatusIndicator/>`

```typescript
type Props = {
  status: 'normal' | 'above' | 'below' | 'unknown';
  size?: 'sm' | 'md';
};
```

Цветной кружок + опциональная подпись. Используется на карточках замеров, в формах ввода, в графиках.

### 13.2. `<MetricSearchSelect/>`

Автокомплит-поиск показателя по справочнику. Поддерживает:
- Поиск по name + synonyms (debounce 200ms).
- Группировку по категориям в dropdown.
- Добавление «Создать пользовательский «X»» при отсутствии совпадений.
- Keyboard navigation (↑↓, Enter, Esc).

### 13.3. `<ReferenceBand/>`

SVG-компонент зелёной полосы на графике. Принимает `min`, `max`, scale-функции Y. Используется внутри `<AnalyteChart/>`.

### 13.4. `<MeasurementCard/>`

Карточка замера в списке. Принимает объект measurement с preview-значениями.

### 13.5. `<Drawer/>`

Bottom-sheet на мобильном, side-drawer на десктопе. Используется для:
- Предпросмотра замера при клике на точку графика.
- Формы добавления показателя.
- Детальной настройки фильтров.

### 13.6. `<FileUploader/>`

Компонент прикрепления файлов с:
- drag-and-drop (desktop);
- выбор источника (file / camera) на mobile;
- progress bar;
- предпросмотр превью.

## 14. Состояния экранов

Каждый экран реализует четыре базовых состояния:

1. **Loading**: skeleton-плейсхолдеры.
2. **Empty**: иллюстрация + призыв к действию.
3. **Error**: «Не удалось загрузить» + кнопка «Повторить».
4. **Content**: основное состояние с данными.

Дополнительно для форм:
- **Submitting**: кнопка disabled + spinner.
- **Validation errors**: подсветка полей.

## 16. Доступность

- Все интерактивные элементы с keyboard navigation.
- Фокус явно виден (`focus-visible:ring`).
- Все иконки без текста имеют `aria-label`.
- Контраст текста — минимум WCAG AA (4.5:1).
- Формы — правильная разметка `<label for>`, `aria-invalid`, `aria-describedby`.
- График сопровождается текстовой альтернативой: последнее значение, тренд, список всех точек (screen-reader only).
- Цветовые статусы дублируются иконкой / текстом (не полагаемся только на цвет).
- Respect `prefers-reduced-motion`: отключать анимации.

## 17. Интернационализация

В MVP — только русский. Но:

- Добавление других языков — без изменения компонентов.

## 18. PWA

- `manifest.json`: имя, иконки, theme-color, display: standalone.
- Service worker:
  - Кеширует статику (JS, CSS, шрифты).
  - Кеширует GET-запросы к `/api/v1/metrics` и `/api/v1/measurements` (stale-while-revalidate).
  - Мутации — только online.
- Install prompt: кнопка «Установить на домашний экран» в /settings при доступности.

## 19. Отсылки к макету заказчика

Макет в ТЗ определяет ключевые элементы:
- **График с цветными линиями** → `<AnalyteChart/>` на `/chart` и в карточке замера.
- **Зелёная полоса референса** → `<ReferenceBand/>`.
- **Интервалы в днях между точками** → подпись над каждым сегментом.
- **Кликабельная полоска «датаконтроль»** → timeline компонент под графиком.
- **Заметка в свободной форме** → `<textarea>` в форме замера и блок в карточке.
- **Файл / Фото / Ввести вручную** → меню в `<FileUploader/>`.
- **Поле ввода + круглая кнопка слева** → форма замера, кнопка с иконкой прикрепления.

Все эти элементы реализованы как отдельные компоненты, что упрощает переработку UI без переписывания логики.
