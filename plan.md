# Health Tracker → Telegram: план реализации

Анализ трёх вариантов переноса функционала Health Tracker
(13 метрик крови, SVG-график, импорт/экспорт JSON, заметки)
в экосистему Telegram.

---

## Вариант 1 — Чистый Telegram-бот

### Описание

Пользователь взаимодействует исключительно через чат: команды,
inline-кнопки, FSM-диалоги. Бот генерирует статичные PNG-графики
и отправляет их в ответ на запросы.

### Стек

| Слой | Технология | Назначение |
|------|-----------|------------|
| Язык | Python 3.11+ | основной язык |
| Фреймворк | aiogram 3 | обработка Telegram API, FSM |
| Графики | matplotlib + seaborn | генерация PNG-графика |
| БД | PostgreSQL | хранение замеров |
| ORM | SQLAlchemy 2 + alembic | схема и миграции |
| Хостинг | Railway / Fly.io / VPS | деплой |
| Переменные | python-dotenv | конфиг токенов |

**Альтернатива на Node.js:** grammY + chartjs-node-canvas + Prisma + PostgreSQL — аналогичный результат, выбор зависит от предпочтений.

### Пользовательский сценарий

```
/start         → приветствие + список команд
/add           → диалог: выбор метрики (inline) → ввод значения → сохранить
/chart         → выбор метрики → PNG-изображение с графиком
/history       → последние N замеров текстом / таблицей
/export        → бот присылает файл data.json
/import        → пользователь присылает JSON → бот парсит и сохраняет
/note текст    → добавить заметку
/delete        → список последних записей с кнопками «Удалить»
```

### Плюсы

- Простейшая инфраструктура: один процесс, одна БД
- Не нужен HTTPS-хостинг для фронтенда
- Работает на слабом VPS ($5/мес)
- Нативный Telegram UX — пользователь не покидает чат
- Легко добавить уведомления-напоминания (cron внутри бота)
- Минимальный порог входа для разработчика

### Минусы

- График — только статичный PNG, без тултипов и зума
- Удаление конкретной записи требует многошагового диалога
- Неудобный ввод при большом количестве метрик (13 кнопок)
- Невозможно показать несколько метрик одновременно
- Плохой UX для просмотра истории (нет скролла таблицы)
- Каждое действие — отдельное сообщение, засоряет чат

### Оценка

| Параметр | Значение |
|----------|---------|
| Сложность | Низкая |
| MVP | 3–5 дней |
| Инфраструктура | VPS + PostgreSQL |
| Цена хостинга | ~$5–10/мес |

## Вариант 2 — Telegram Mini App (WebApp)

Telegram Mini App — это полноценное веб-приложение, открывающееся
внутри Telegram по кнопке. Текущий `index.html` переносится
с минимальными изменениями.

---

### Подвариант 2A — Mini App без бэкенда

#### Описание

Текущий `index.html` деплоится как статичный сайт (Vercel, GitHub Pages).
Бот содержит одну кнопку, открывающую Mini App. Хранилище — `localStorage`
встроенного браузера Telegram (постоянный, не очищается).

#### Стек

| Слой | Технология | Назначение |
|------|-----------|------------|
| Фронтенд | Текущий index.html | весь UI и логика |
| SDK | Telegram WebApp JS | интеграция с Telegram |
| Хостинг | Vercel / GitHub Pages | бесплатный HTTPS |
| Бот (минимум) | aiogram / grammY | одна кнопка WebApp |
| Хранилище | localStorage | данные на устройстве |

#### Изменения в коде index.html

```html
<!-- 1. Добавить в <head> -->
<script src="https://telegram.org/js/telegram-web-app.js"></script>

<!-- 2. В начале <script> -->
Telegram.WebApp.ready();
Telegram.WebApp.expand(); // на весь экран
```

Итого изменений: **~5 строк кода**.

#### Плюсы

- Запускается за **1 день** — минимальные изменения кода
- Полноценный SVG-интерфейс с тултипами — ничего не теряется
- Бесплатный хостинг (Vercel free tier)
- Не нужен бэкенд и БД
- Полный импорт/экспорт JSON сохраняется
- Нет серверных расходов

#### Минусы

- Данные привязаны к **одному устройству** — нет синхронизации
- Потеря данных при переустановке Telegram или смене устройства
- Нельзя добавить уведомления-напоминания
- Нельзя поделиться данными с врачом / другим пользователем
- localStorage в Telegram WebView не всегда надёжен на iOS

#### Оценка

| Параметр | Значение |
|----------|---------|
| Сложность | Очень низкая |
| MVP | 1 день |
| Инфраструктура | Только хостинг фронта |
| Цена хостинга | $0 (Vercel free) |

---

### Подвариант 2B — Mini App + REST API + облачная БД

#### Описание

Фронтенд (текущий `index.html`) заменяет вызовы `localStorage`
на `fetch()` к REST API. Бэкенд хранит данные в PostgreSQL,
привязанных к `Telegram user_id`. Авторизация — через
`Telegram.WebApp.initData` (подписанные данные от Telegram).

#### Архитектура

```
┌──────────────┐     WebApp     ┌─────────────────┐
│   Telegram   │ ─────────────► │  index.html      │
│   клиент     │                │  (Vercel)        │
└──────┬───────┘                └────────┬─────────┘
       │ Bot API                         │ fetch()
       ▼                                 ▼
┌──────────────┐             ┌───────────────────────┐
│  Telegram    │             │   REST API            │
│  Bot         │             │   FastAPI / Express   │
│  (aiogram)   │             │                       │
└──────────────┘             └───────────┬───────────┘
                                         │
                                         ▼
                             ┌───────────────────────┐
                             │   PostgreSQL           │
                             │   (Railway / Supabase) │
                             └───────────────────────┘
```

#### Стек

| Слой | Технология | Назначение |
|------|-----------|------------|
| Фронтенд | index.html (~80% без изменений) | весь UI |
| SDK | Telegram WebApp JS | авторизация, тема |
| API | FastAPI (Python) или Hono (TS) | REST endpoints |
| Авторизация | HMAC-проверка initData | верификация пользователя |
| БД | PostgreSQL | хранение замеров |
| ORM | SQLAlchemy / Prisma | работа с БД |
| Бот | aiogram 3 / grammY | кнопка + уведомления |
| Хостинг фронта | Vercel | статика + HTTPS |
| Хостинг бэка | Railway / Fly.io | API + бот |

#### Изменения в index.html

Заменить функции хранилища:

```js
// Было:
function getData() { return _data; }
function saveData(data) { _data = data; save(data); }

// Станет:
async function getData() {
  const res = await fetch('/api/measurements', { headers: authHeaders() });
  return res.json();
}
async function saveData(data) {
  await fetch('/api/measurements', {
    method: 'POST',
    headers: { ...authHeaders(), 'Content-Type': 'application/json' },
    body: JSON.stringify(data),
  });
}

function authHeaders() {
  return { 'X-Telegram-Init-Data': Telegram.WebApp.initData };
}
```

Объём изменений в `index.html`: **~50–80 строк** (замена хранилища,
добавление async/await, loader-состояние при загрузке).

#### API endpoints

```
GET  /api/measurements          → все замеры пользователя
POST /api/measurements          → добавить замер
DELETE /api/measurements/{id}   → удалить замер
GET  /api/measurements/export   → JSON-файл
POST /api/measurements/import   → загрузить JSON
GET  /api/notes                 → заметка пользователя
PUT  /api/notes                 → сохранить заметку
```

#### Плюсы

- Синхронизация между всеми устройствами
- Данные не теряются при переустановке
- Можно добавить уведомления-напоминания через бота
- Можно поделиться данными (например, ссылка для врача)
- Полноценный SVG-интерфейс сохраняется
- Тема Telegram (светлая/тёмная) через `colorScheme`
- Масштабируется до многопользовательского сервиса

#### Минусы

- Значительно больше инфраструктуры
- Нужно разворачивать и поддерживать бэкенд
- Все вызовы данных становятся асинхронными → нужен loader
- Платный хостинг бэка (~$5–15/мес)
- Верификация `initData` требует аккуратной реализации (безопасность)
- Время разработки: 1–2 недели

#### Оценка

| Параметр | Значение |
|----------|---------|
| Сложность | Средняя |
| MVP | 1–2 недели |
| Инфраструктура | Vercel + Railway/Fly + PostgreSQL |
| Цена хостинга | $5–15/мес |

## Вариант 3 — Гибрид: Mini App + бот с уведомлениями

### Описание

Полноценный продукт: Mini App (вариант 2B) дополняется активным ботом.
Бот не просто открывает приложение — он проактивно взаимодействует
с пользователем.

### Дополнительный функционал бота

```
/start         → кнопка «Открыть трекер» (открывает Mini App)
/remind        → настроить напоминание добавить замер (ежедневно в N часов)
/quick 5.2     → быстро добавить замер текущей метрики без открытия UI
/summary       → краткая сводка последних значений текстом
/share         → сгенерировать PDF-отчёт и прислать файлом
```

### Стек

Всё из варианта 2B плюс:

| Слой | Технология | Назначение |
|------|-----------|------------|
| Планировщик | APScheduler / node-cron | уведомления в заданное время |
| PDF | ReportLab (Python) / PDFKit (Node) | экспорт отчёта |
| Redis (опц.) | Redis | хранение расписаний уведомлений |

### Плюсы

- Наиболее полноценный UX
- Пользователь может быстро добавить замер без открытия приложения
- Напоминания снижают «забывчивость» — ключевая проблема трекеров
- PDF-экспорт для врача
- Сочетает удобство чата и мощь веб-интерфейса

### Минусы

- Наибольшая сложность разработки
- Больше кода для поддержки
- Redis добавляет ещё один сервис в инфраструктуру
- Время разработки: 2–4 недели

### Оценка

| Параметр | Значение |
|----------|---------|
| Сложность | Высокая |
| MVP | 2–4 недели |
| Инфраструктура | Vercel + Railway + PostgreSQL + Redis |
| Цена хостинга | $10–20/мес |

## Рекомендованный путь

**Шаг 1 (сегодня):** задеплоить текущий `index.html` на Vercel,
создать бота с кнопкой → **рабочий Mini App за 1 день, бесплатно** (v2A).

**Шаг 2 (при необходимости):** добавить бэкенд и БД для синхронизации (v2B).
Фронтенд меняется минимально — только слой хранилища.

**Шаг 3 (продукт):** добавить активного бота с уведомлениями (v3).

---

Структура:


bot/
  bot.py            — бот
  requirements.txt
  .env.example
  miniapp/
    index.html      — мини-приложение
Запуск:


pip install -r bot/requirements.txt

# Windows
set BOT_TOKEN=123456:ABC...
set MINIAPP_URL=https://your-domain.com/miniapp
python bot/bot.py
Важный момент — MINIAPP_URL должен быть HTTPS. Telegram не открывает WebApp по HTTP. Для локальной разработки удобнее всего ngrok:


# в одном терминале — раздаём miniapp/
npx serve bot/miniapp -p 8080

# в другом — туннель
ngrok http 8080
# ngrok выдаст https://xxxx.ngrok-free.app — вставь его в MINIAPP_URL
Также нужно зарегистрировать домен мини-приложения у @BotFather: /mybots → Bot Settings → Menu Button → Edit Menu Button URL или просто через WebApp кнопку — домен не требует регистрации, если используется InlineKeyboardButton с web_app.
